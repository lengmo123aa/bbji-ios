# BBji iOS（M0 · 链路验证）

目标：**先证明能装上、能开、能登录、杀掉重开还登着**，再往里填页面。

## 你（用户）要做的
1. 注册一个 GitHub 账号（忘了旧的没关系，2 分钟新注册一个）
2. 新建一个**公开**仓库（Public）—— 公开仓库的 macOS 构建分钟**免费不限**
3. 把这个文件夹里的东西全传上去（网页上拖拽上传即可，或者用 GitHub Desktop）
4. 打开仓库页 → **Actions** → 左边选「Build BBji iOS」→ 右边 **Run workflow** → 等 3~6 分钟
5. 跑完点进这次运行，最下面 **Artifacts** → 下载 `BBji-iOS-0.0.1-ipa`（是个 zip，里面是 ipa）
6. 解压出 ipa → 丢进**巨魔**安装 → 打开试

## 这一版有什么
- 原生登录页（真的连 `bbji.xkmd.cn/api/login`，token 存本机，重开还在）
- 三个 Tab 骨架：消息 / 通讯录 / 我
- 「我 → 设计稿」里能看到我们画好的 55 屏（网页壳，顺便验证"边缘页走网页"这条路）

## 不签名/巨魔说明
- 包是**未签名**的（CI 里 `CODE_SIGNING_ALLOWED=NO`），最后用 `ldid -S` 做了假签名 —— 巨魔认这个。
- 装的时候如果巨魔提示已存在，选**覆盖安装**，登录态不会丢。
